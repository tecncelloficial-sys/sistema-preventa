# Sistema de Preventa - Control de Local

## IMPORTANTE al subir a GitHub
NO uses "Create new file" ni pegues el codigo dentro del editor de texto de GitHub.
Eso corrompe los caracteres especiales del archivo (comillas, simbolos) y rompe la app.

Usa SIEMPRE: "Add file" -> "Upload files" -> arrastrar el archivo index.html
tal cual, sin abrirlo ni editarlo en el editor web de GitHub.

## Como verla online (GitHub Pages)
1. Settings del repo -> Pages
2. Source: rama main, carpeta / (root)
3. Guardar. En 1-2 min: https://TU-USUARIO.github.io/NOMBRE-REPO/
